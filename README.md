## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
git clone https://github.com/1nc0gn30/netlify-cli-agent-runner.git
cd netlify-cli-agent-runner
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

  npm run lint - eslint .
